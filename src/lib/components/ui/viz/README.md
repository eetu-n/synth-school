# Visualizers (`src/lib/components/ui/viz`)

Audio visualizers and educational signal diagrams:

- **Time & Frequency Domain**: `Scope.svelte` (canvas oscilloscope), `Frequency.svelte` (spectrum analyzer with filter response overlays).
- **Educational Demonstrations**: `AdsrVis.svelte` (ADSR envelope curve), `SignalAddition.svelte` (additive harmonics), `AliasingChart.svelte` (sample rate aliasing).
- **General Utilities**: `Chart.svelte` (line charts via Chart.js), `RoutingGraph.svelte` (audio node connection topology).
